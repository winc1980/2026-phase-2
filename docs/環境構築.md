# このドキュメントについて

このドキュメントには、学習用軽音タイムテーブルの環境構築の方法を記載する。学習を始める際や詰まった時に適宜確認すること。

# STEP.1 Bunのインストール

まずBunがPCにインストールされているかを確認する。

<details>

<summary>What is Bun? (▶︎ここを押すと詳細な説明を確認できる) </summary>

# Bun とは

Bun(バン)とは、Node.js/npmに代わる超高速なJavascript実行環境・パッケージマネージャーです。

> [!note]
> 実行環境とは、あるプログラミング言語をコンピュータで実行できるようにするソフトウェア群をいう。JavaScriptでは`Node.js`や`Bun`、`Deno`などがある。今回は高速な`Bun`を使う。

 <details>

 <summary>JavaScriptの実行環境について</summary>

JavaScriptは元来**ブラウザ上**で動作することを目的に開発された特殊なプログラミング言語である。しかし、後世になりバックエンドを含めてJavaScriptで一貫してシステムを構築できるよう、コンピュータ上で直接実行できる`Node.js`という実行環境が用意された。今は`Bun`が代替となりつつある。

 </details>

</details>

```cmd
bun -v
```

```cmd
1.3.x
```

のように出ていたら次のステップに進む。

> [!warning]
> Windows利用者へ
> PowerShellのExecutionPolicyによっては、bunがインストールされていても、実行できない可能性があります。
> Powershellを開いて、
>
> ```powershell
> Get-ExecutionPolicy
> ```
>
> を実行して、
>
> ```powershell
> Restricted
> ```
>
> と表示される場合は、ExecutionPolicyが問題となっています。
>
> ```powershell
> Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
> ```
>
> を実行し、ターミナルを開き直して、インストールできているのかの確認をしなおしてください。

```cmd
command not found
```

などのエラーが出た場合は[このリンク](https://bun.com/docs/installation)を参照してBunをインストールする。

※ 注意:**mac** の場合は`curl`コマンドではなく`Homebrew`を使ってインストールする。Bunのインストールガイドでは`Package Managers` -> `Homebrew`の順に選択し、以下のコマンドを実行する。

```cmd
brew install oven-sh/bun/bun
```

※ Homebrewがインストールされていない場合は[このサイト](https://brew.sh/ja/)を参照しインストールする。

> [!warning]
> パッケージをインストールしたら、ターミナルを開き直す。

# STEP.3 クローンする

1. 上記画像を参考にGithub CLIコマンドをコピーする。
2. 実行する。

# STEP.4 パッケージをインストールする

1. プロジェクトのルートディレクトに移動する

```sh
 cd (your_path)/winc-phase-2
```

> [!note]
> 要するに、あなたの作業ディレクトリに`cd`コマンドで移動して、ということ。

2. パッケージをインストールする

```sh
 bun install
```

> [!note]
> このプロジェクトで使用するパッケージを一括でインストールするコマンド

<details>
<summary>依存関係とは?</summary>
パッケージとそのパッケージが要求する他のパッケージの関係。つまり、必要なものである。
</details>

3. 必要なコマンドを打つ

```sh
 bunx drizzle-kit push
```

> [!note]
> `bunx`とは、PC上にないパッケージのコマンドを実行できるものである。ここでは、`bunx`の後に続く`drizzle-kit`というコマンドを実行している。

<details>

<summary>何をしている？</summary>

データベースを扱いやすくするORMを準備しています。

> [!note]
> データベースとは、データを永続的に保存できるもので、代表的なものに`MySQL`,`Postgress`などがあります。今回は`sqlite`を使う。

> [!note]
> Object Relation Mapper。ORMとは、プログラミング言語からデータベースを扱うために使う便利なツール群。SQL文を直接書くより、言語の文法で型安全に書くことができる。

</details>

# STEP.5 開発サーバを起動する

```cmd
 bun run dev
```

localhostでサーバが起動する。
ターミナル上のリンクは`Ctrl` + `Click` (Macは`Command` + `Click`)で開ける。

> [!note]
> VSCodeの内部ブラウザではなく、Google Chromeを使用すると良い。`bun run dev`を実行したターミナル上で`o`を入力して`enter`すると、Google Chromeで開ける。
