title: トップページから各ページへの導線がない
---

このアプリケーションに最初にアクセスしたとき（`/`）に表示されるページには、リンクが1つもありません。
そのため、アプリを使い始めることができない状態になっています。

対象のファイルは`app/routes/home.tsx`です。

## 1 今の状態を確認する

開発サーバを起動して、トップページを開いてみましょう。

```sh
bun run dev
```

「トップページ」という見出しとメッセージしか無く、ログインページへ行く手段がないことを確認してください。

## 2 ログインページへのボタンを作る

`/auth/login`へ遷移するボタンを用意しましょう。

React Routerでページを移動するには、`react-router`の`Link`コンポーネントを使います。

> [!note]
> `<a href="...">`ではなく`<Link to="...">`を使います。
> `<a>`だとページ全体が再読み込みされてしまいますが、`Link`なら必要な部分だけを差し替えて高速に移動できます。

ボタンを作るときは、自分で`<button>`にスタイルを当てるのではなく、すでに用意されている部品を使うとよいです。
このプロジェクトには`~/components/ui/button`に共通の`Button`コンポーネントが用意されています。
アプリ内のボタンはすべてこの`Button`を使うことで、見た目（色・角丸・余白など）がアプリ全体で統一されます。逆に、ここで自作のボタンを作ってしまうと、ページごとに見た目がバラバラなアプリになってしまいます。

> [!important]
> ボタンが必要になったら、まず`~/components/ui/button`に使えるものがないか確認する。これがデザインを統一するための基本ルールです。

`Button`と`Link`を組み合わせる書き方は`app/routes/app/home.tsx`に実例があるので、そちらを参考にしてください。

## 3 追加：他のページへの導線も用意する

以下のページへのリンクも追加しましょう。

- `/auth/register`（新規アカウント登録）
- `/app`（アプリのホーム）

> [!note]
> 遷移先のパスがどう決まっているのかは`app/routes.ts`を見ると分かります。

## 4 発展：トップページのUIをアレンジする

見出しとボタンが並んでいるだけの状態から、アプリの入り口らしい見た目にしてみましょう。

- アプリの名前や説明文を追加する
- ボタンの大きさや色を変えてみる（`Button`の`variant`や`size`を変えてみる）
- Tailwind CSSのクラスでレイアウトを整える

正解はありません。自分が使いたくなるトップページにしてみてください。

## 5 達成条件

- [ ] トップページ（`/`）から`/auth/login`へ、共通の`Button`コンポーネント（`~/components/ui/button`）を使ったボタンで遷移できる
- [ ] ページ遷移に`<a>`ではなく`Link`コンポーネントが使われている
- [ ] `/auth/register`・`/app`への導線も追加されている

（セクション4の見た目のアレンジは正解の無い任意項目のため、達成条件には含めません）
